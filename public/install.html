安装向导

三步完成初始化：环境自检 → 创建管理员 → 写入安装锁。安装完成后本入口将自动锁定。

1 · 运行环境自检

    2 · 站点与支付配置

    用于生成支付回调地址，必须与浏览器访问的地址一致（含 https://，结尾不要带 /）
    留空则暂不启用在线支付，只保留余额支付；之后可在 config/.env 里补填

    3 · 创建管理员账号

    3–32 位，仅限字母、数字、下划线、点、短横
    密码要求：至少 10 位，且同时包含字母和数字（与后端校验规则一致）。 密码以 Argon2id 哈希存储，不会明文保存。

    4 · 安装锁

    安装成功后会在 config/installed.lock 写入锁文件（权限 0600，位于 Web 根之外； 命令行以 root 安装时会自动移交给 Web 服务用户，避免 FPM 读不到而误判未安装）。 此后访问本页面会提示「已安装」并拒绝再次执行，防止站点被重复初始化。
